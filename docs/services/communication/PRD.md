# Communication Service - Product Requirements Document

## Feature Overview

### Email Templates
- Create and edit email templates using visual editor
- MJML-based responsive email design
- Preview in multiple viewport sizes
- Template versioning and history

### Flow Builder
- Visual drag-and-drop flow designer
- Conditional branching logic
- Multiple trigger types (event, schedule, manual)
- Flow activation/deactivation

### Transaction Tracking
- View all sent communications
- Filter by date, status, recipient
- Detailed delivery status
- Retry failed deliveries

### Reporting
- Communication metrics dashboard
- Delivery success rates
- Engagement analytics
- Export capabilities

## User Stories
1. As a marketing user, I can create email templates visually
2. As an operations user, I can design communication flows
3. As an admin, I can view transaction history and reports
